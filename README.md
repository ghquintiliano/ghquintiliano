### 🧭 Quem eu sou

Sou técnico em mecatrônica, com experiência em manutenção de eletrônica industrial (CLPs, sensores, automação de chão de fábrica). Estou fazendo Engenharia da Computação e migrando para desenvolvimento backend, com Java como linguagem principal.

O objetivo de longo prazo é DevSecOps — mas construído em cima de uma base sólida de backend, não como atalho. Ainda estou nos fundamentos, e prefiro mostrar isso com transparência a inflar o currículo.

### 🎯 Trajetória

```
Java Core (atual) → SQL/PostgreSQL → Spring Boot → Projeto IoT (diferencial) → Docker/AWS → DevSecOps
```

A camada de segurança (OWASP, SAST/DAST, CI/CD seguro, Kubernetes) entra dentro dessas fases, não depois delas — é assim que pretendo chegar em DevSecOps sem pular etapa.

### 🏭 O que me diferencia

A maioria de quem chega em backend ou DevSecOps nunca colocou a mão numa máquina de verdade. Eu já diagnostiquei falha em sensor industrial, li esquema elétrico com PIC e mexi em CLP no chão de fábrica. Isso é raro nesse mercado — e é a direção que quero seguir dentro de segurança: sistemas industriais (OT/ICS) são uma área onde poucos DevSecOps têm experiência de campo real.
